# ryanbmarx.github.io

Personal portfolio site. SvelteKit + `adapter-static`, fully prerendered, deployed to
GitHub Pages under the custom domain in `static/CNAME`.

GitHub Pages serves static files only — there is no server to run at request time.
Every route must be fully static-renderable: no URL search params, no server `load`
functions, no API routes. All data must be resolvable at build time.

## Routing

- `src/routes/+layout.svelte` — root layout. Picks one background component at
  random from `src/routes/_components/background/*.svelte` via `import.meta.glob`
  and renders it fixed behind everything. Drop a new `.svelte` file in that folder
  and it joins the rotation automatically — no wiring needed.
- `src/routes/+page.svelte` — homepage, intentionally bare-chrome (its own
  nav, no shared Nav/Footer).
- `src/routes/(interior)/` — route group for sub-pages (`about`, `projects`).
  Its `+layout.svelte` adds the shared Nav/NavMobile/Footer chrome and a `<Section>`
  wrapper; page title and `fullwidth` flag come from each route's `+page.ts` `load()`.
- Folders prefixed with `_` (e.g. `_components`) are SvelteKit's convention for
  non-route folders colocated with routes.
- `$lib` is for components/hooks shared across routes; route-local components live
  in that route's own `_components` folder instead (see `about/_components/Resume.svelte`).

## Content

- `aboutMe.md` is real Markdown, imported with the `?raw` suffix and rendered via
  `marked.parse(src, { async: false })` + `{@html}`. Passing `async: false`
  explicitly is what keeps the return type a plain `string` (avoids an `as` cast).
- The nav SVG sprite is generated by `npm run svg` (`svg-sprite` over `src/svg/**/*.svg`
  into `src/lib/sprite.svg`), then injected with `?raw` + `{@html}` in a hidden div.
- `src/routes/(interior)/projects/items.ts` has at least one known broken internal
  link and the site references a `favicon.png` that doesn't exist — both pre-existing.
  `svelte.config.js` sets `handleHttpError`/`handleMissingId` to `"warn"` so these
  don't fail the static build.

## Known intentional oddities

- `src/lib/components/NavMobile copy.svelte` is unused scratch/dead code, kept on
  purpose — don't delete without asking.
- ESLint disables `svelte/no-navigation-without-resolve` (no dynamic routes here),
  `svelte/no-at-html-tags` ({@html} is only ever used on trusted local content —
  markdown and the SVG sprite), and `no-undef` (TypeScript already covers it).

## Commands

- `npm run dev` / `npm run build` (runs `svg` then `vite build`) / `npm run preview`
- `npm run check` — svelte-check
- `npm run lint` — eslint
- `npm run format` / `npm run format:check` — prettier
- Deploy is automatic via `.github/workflows/deploy.yml` on push to `main`.
